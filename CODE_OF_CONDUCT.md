# Code of Conduct

FAIM-Native is intended to be a respectful technical community. Participants are expected to:

- be welcoming and constructive;
- discuss ideas and evidence rather than attack people;
- assume good intent while taking reported harm seriously;
- respect different backgrounds, experiences, and technical viewpoints;
- keep security reports, private data, and credentials confidential; and
- accept thoughtful correction and focus on improving the project.

Harassment, discrimination, threats, deliberate disruption, doxxing, sexualized conduct, and sharing private information without consent are not acceptable.

## Enforcement

Report conduct concerns privately to the repository maintainers (`@sainibhaowal`) with links, dates, context, and relevant evidence. For issues involving exposed credentials or security impact, follow [`SECURITY.md`](SECURITY.md) or submit a private security report via [GitHub Security Advisories](https://github.com/sainibhaowal/FAIMatrix/security/advisories/new). For general repository policy questions, see [`SUPPORT.md`](SUPPORT.md).

Maintainers review all reports, maintain confidentiality for reporters, and may remove content, close threads, or restrict repository participation as appropriate.
