# Code of Conduct

FAIM-Native is intended to be a respectful technical community. Participants are expected to:

- be welcoming and constructive;
- discuss ideas and evidence rather than attack people;
- assume good intent while taking reported harm seriously;
- respect different backgrounds, experiences, and technical viewpoints;
- keep security reports, private data, and credentials confidential; and
- accept thoughtful correction and focus on improving the project.

Harassment, discrimination, threats, deliberate disruption, doxxing, sexualized conduct, and sharing private information without consent are not acceptable.

## Enforcement

Report conduct concerns privately to the project maintainers through the repository's configured contact channel. Include links, dates, context, and any relevant evidence. Maintainers may remove content, restrict participation, or take other action appropriate to the situation.

This is a concise project policy. If the project adopts a formal community organization, it should replace or extend this document with a reviewed code of conduct and named enforcement contacts.
