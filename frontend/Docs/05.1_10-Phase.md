**Core Formula**
Use one deterministic final score:

```text
S(d|q) =
w1*S_char
+ w2*S_word
+ w3*S_phrase
+ w4*S_entity
+ w5*S_graph
+ w6*S_temporal
+ w7*S_concept
+ w8*S_evidence
- w9*S_opp
- w10*S_red
```

Constraints:

- every subscore normalized to `[0,1]`
- `sum(w)=1`
- stable sorting on ties
- no randomness anywhere


fixed iterations only, deterministic.
