# Trademark and branding policy

The names **FAIM**, **FAIM-Native**, **FAIMATRIX**, the FAIM logo, and related product marks are project branding. The Apache License 2.0 grants rights to the software; it does not grant permission to use project trademarks.

## Permitted descriptive use

You may use the project name to accurately describe unmodified software, compatibility, or origin, for example:

> Built with FAIM-Native.

You may link to this repository and refer to an unmodified fork as a fork of FAIM-Native.

## Uses that require permission

Do not use the project names, logos, or confusingly similar branding to:

- imply that a fork, hosted service, plugin, or derivative product is official or endorsed;
- name a modified distribution as if it were the official FAIM-Native release;
- register a company, domain, package, or product using the marks in a way that creates confusion; or
- alter the logo or combine it with other branding without permission.

For a modified distribution, use a distinct product name and describe it as “based on FAIM-Native” where accurate.

This document is a project policy, not a trademark registration or legal opinion. The rights holder should update it with the final legal entity and registration details before a public commercial launch.
